# أول حرف عربي

### حكايات تبدأ بالعربية، وتصل إلى العالم.

**Arabic-first fiction · Multilingual editions · Digital & print publishing**

</div>

أول حرف عربي مؤسسة مستقلة لتطوير الروايات والسلاسل الأدبية ونشرها بلغتها الأصلية العربية، ثم نقلها إلى لغات أخرى مع الحفاظ على الجودة والهوية الثقافية.

- كل رواية أو سلسلة لها مستودع مستقل، ويمكن أن تتألف من أجزاء متعددة.
- المخطوطات وحقوق النشر والمراجعات ملفات خاصة.
- أدوات النشر مشتركة عبر `publisher-engine`.
- الروايات لا تُنشر تجارياً قبل اعتماد النص والحقوق والتصميم.

> هذا الملف هو ملف تعريف أولي؛ الشعارات والعلامات التجارية والحقوق الإدارية لم تُسجّل بعد.
