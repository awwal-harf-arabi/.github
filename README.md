# أول حرف عربي — Organization configuration

This public repository provides the GitHub organization profile at [`profile/README.md`](profile/README.md).

**Organization:** https://github.com/awwal-harf-arabi  
**Independent publishing engine:** https://github.com/awwal-harf-arabi/publisher-engine

The organization is independent from Fenix. Original Arabic manuscripts, unreleased translations, and internal editorial material remain in private novel repositories; only reusable tooling and the public profile are public.

## Repository responsibilities

- `.github`: public organization identity and documentation.
- `publisher-engine`: reusable Python publishing CLI and its tests.
- `novel-template`: private multilingual series template.
- `ardan-chronicles`: private five-volume story planning vault.

Published editions must pass editorial, rights, translation, and format-specific quality gates. Do not place secrets or unlicensed content in public repositories.
