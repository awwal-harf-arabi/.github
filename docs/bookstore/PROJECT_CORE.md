# أول حرف عربي — مشروع متجر الكتب المستقل
status: proposed
updated_at: 2026-11-01

## 1. Project Overview
- **اسم العمل:** مكتبة أول حرف (اسم واجهة مبدئي)، ضمن مؤسسة «أول حرف عربي».
- **النوع:** متجر نشر إلكتروني مستقل لبيع روايات أصلية وسلاسل متعددة الأجزاء واللغات.
- **الملكية:** مستقلة تماماً عن Fenix؛ حسابات وبنية تحتية وسجلات دفع وبيانات حقوق منفصلة.
- **المصادر الأدبية:** مستودعات GitHub خاصة، واحد لكل رواية/سلسلة.
- **أول منتج محتمل:** «سجلات أَرْدان — جرس الرَّفْد» بعد اعتماد المخطوط والغلاف والحقوق.
- **العملاء:** قراء الفانتازيا العربية ثم القراء عالمياً عند اعتماد ترجمات منفصلة.
- **التحويل الأساسي:** اكتشاف السلسلة -> قراءة عينة مجانية -> شراء Edition محددة -> الحصول على ترخيص تنزيل في مكتبتي.
- **المرحلة الحالية:** تخطيط متجر. لا يوجد مستودع bookstore أو موقع نشر حي ولا تحقق دفع.
- **المستودع المقترح:** awwal-harf-arabi/bookstore (private، منفصل عن ملفات الروايات).

## 2. Business Understanding
القيمة: كتب عربية أصلية ذات عالم غني، جودة تحرير عالية، نسخ رقمية/ورقية موثوقة، ومكتبة قابلة لإعادة تنزيل النسخ التي اشتراها القارئ.

الزبون لا يشتري «مخطط قصة» بل كتاباً نهائياً مرخصاً، يختار لغته وصيغته. لا يُفعّل الدفع على إصدار draft/review/proof.

## 3. Brand Direction
- اسم الواجهة: **أول حرف عربي**.
- هوية بصرية: تحريرية هادئة؛ الخلفية بلون الورق، تباين حبر داكن مع معدن نحاسي محدود؛ ليس موقع ألعاب صاخباً.
- الصور: أغلفة معتمدة فقط، ومشاهد بصرية اختيارية لا تحرق الأحداث.
- الخط: خط عربي كتابي مقروء + خط واجهة عربي واضح؛ تراخيص الخطوط وحقوق الاستخدام يجب مراجعتها.
- الأزرار والألوان تجتاز WCAG عند التنفيذ.
- لا استعمال لشعارات Fenix أو قاعدة حساباتها.

## 4. Website Scope
### المسارات العامة
- /ar أو /en للواجهة، واتجاه الصفحة بحسب locale.
- /series/{slug} صفحة السلسلة، التسلسل، الأجزاء وإصدارات اللغات.
- /books/{slug} وصف الكتاب، غلافه، اللغة، الصيغة، المؤلف، مقتطف غير كاشف، بيانات الإصدار والسعر.
- /sample/{edition} عينة مجانية مأذونة منشورة فقط.
- /cart و /checkout عملية شراء مختصرة.
- /my-library كتب المشتري المملوكة له وصيغ التحميل المتاحة.
- /orders/{order} فاتورة وسجل الدفع عند تحقق الملكية.
- /legal/terms و /legal/privacy و /legal/refunds و /contact.
- /admin لوحة إدارة المحتوى والمنتجات والطلبات والتنزيلات عبر Filament.

### MVP مبسّط
بيع النسخ الإلكترونية EPUB وPDF، وعرض المنتجات في المتجر حسب edition لا حسب رقم الكتاب فقط. تجنّب العروض المسبقة والتقييمات الوهمية.

### لاحقاً
- بيع مطبوع (مخزون أو طباعة حسب الطلب + مناطق شحن وتكاليف فعلية).
- حزم السلاسل، الخصومات، قوائم القراءة والمراجعات الخاضعة للإشراف.
- الصوتيات بعد امتلاك الحقوق ومعايير الجودة.

## 5. Technical Stack
- Laravel 13/PHP 8.4/PostgreSQL؛ تثبيت الإصدارات الفعلية عند إنشاء المستودع.
- Blade + Livewire 4 + Alpine.js + Tailwind CSS 4؛ Filament 5 للإدارة، بناءً على التوافق الرسمي.
- Redis للصفوف والتخزين المؤقت وقيود المعدل؛ Postgres مصدر الحقائق.
- ملفات الكتب خارج public/ على مخزن S3-compatible خاص مع تشفير وسياسة منع العمومية.
- GitHub Actions للبناء المسبق (في الرواية)؛ إدخال كتالوج منشور فقط عبر manifest موقَّع/موثّق.
- بريد للطلبات والروابط وإثبات الدفع؛ مراقبة للأخطاء والويبهوك.

## 6. Languages and Direction
- واجهة عربية افتراضياً، مع i18n independent عن ترجمة الروايات.
- رمز لغة BCP 47 لكل edition؛ ترجمات مهنية مع مراجعة بشرية لكل لغة.
- مبدئياً واجهة ar/en، واستعداد معماري لـ120+؛ لا إعلان توفر لغة لم ينتج مخطوطها.
- lang وdir على HTML لكل لغة؛ hreflang/canonical للإصدارات المنشورة فقط.
- لا تحميل مكتبة ترجمات 120 لغة لكل زائر؛ نطاق locale المطلوبة فقط.

## 7. Checkout and Delivery
1. العميل يختار Edition وصيغة أو حزمة معلنة.
2. يُنشأ Order ذو سعر ثابت وعملة محددة + idempotency key.
3. يرسل المتجر طلب إنشاء دفع إلى مزود وافق على نشاط الكتب الرقمية وبلد تسجيل التاجر.
4. يعود المزود Webhook مُوقع؛ يتحقق الخادم من التوقيع ورقم المبلغ والعملة والحالة وعدم التكرار.
5. ضمن transaction يُعدّل Payment/Order ثم يُنشأ Entitlement/License واحد لكل عنصر مستحق.
6. GET download يطبّق auth+policy+rate limit ويرجع رابطاً موقعاً قصير العمر للملف الخاص، مع سجل audit.
7. لا يُفعّل حق القراءة اعتماداً على redirect من متصفح العميل وحده؛ مصدر الحقيقة هو webhook الموثَّق أو تحقق API موثوق.

## 8. Payment feasibility
- إذا كان الكيان التجاري مسجلاً في لبنان: **Stripe ليس في قائمة الدول المدعومة مباشرة حالياً**، فلا يُستخدم افتراضياً من دون كيان قانوني مؤهل.
- Whish Pay يذكر دعمه للمواقع المخصصة والدفع من رصيد Whish، لكن يجب تأكيد onboarding والـAPI ومجالات التغطية والتسوية والشروط رسمياً.
- يحتاج البيع الدولي إلى قناة بطاقات/تسوية مناسبة للكيان القانوني بعد تحقق أهلية. لا نفترض قبول مزود دون عقد.
- طبقة PaymentGateway Interface مستقلة عن أسماء المزودين مع provider transactions وwebhooks؛ لا تُخزن بيانات بطاقات على خوادمنا.

## 9. Compliance / commercial readiness
- حقوق المؤلف والترجمات والرسوم والأغلفة والخطوط موثقة.
- سياسة استعمال وترخيص نسخ إلكترونية، سياسة خصوصية GDPR/محلية بحسب سوق التوزيع، سياسة استرداد تراجع مع مختص قانوني.
- ضرائب بيع المنتجات الرقمية حسب موطن التاجر والمشتري؛ لا تفترض ضريبة واحدة عالمياً.
- ISBN اختياري/مطلوب حسب قناة البيع والصيغة؛ لا تُخترع أرقام ISBN.
- مواصفات طباعة وموافقة مطبعة قبل طباعة ورقية، ولا يتم وصف الـPDF بأنه جاهز للطباعة دون Preflight.
- منع فهرسة الملفات الكاملة، وعدم إدراج الملفات الخاصة في مستودعات GitHub عامة.
- النسخ التجريبية المجانية لا تحتوي أسرار المؤلف أو ملفات التحرير.

## 10. UX Strategy
### الصفحة الرئيسية
Hero كتاب مميز بعينة مجانية -> السلاسل -> أحدث الإصدارات المتاحة فعلاً -> لماذا القراءة من أول حرف -> الأسئلة عن الصيغ/الأجهزة -> دعوة للاشتراك البريدي (بموافقة صريحة).
### صفحة المنتج
العنوان والغلاف والفصل في السلسلة، اللغة، ما سيحصل عليه القارئ، نوع الترخيص، sample، سعر واضح، طرق الدفع المعتمدة، أي قيود إقليمية.
### Mobile
CTA شراء واضح، sample بنقرة، وصول لمكتبتي والتنزيل؛ تخفيف المؤثرات واحترام reduced-motion.
### Accessibility
تنقل بلوحة المفاتيح، alt للأغلفة، تسميات controls، تباين مقروء، رسائل checkout واضحة بدون تضليل.

## 11. SEO
- صفحات indexable فقط للكتب/الإصدارات المعتمدة والمنشورة.
- JSON-LD Book و Product/Offer عند وجود سعر وعرض حقيقي، breadcrumbs، OpenGraph مع صور غلاف مصرح بها.
- محركات البحث لا ترى المخطوطات الخاصة أو محتوى sample المحجوب.
- hreflang دقيق للغة واجهة/إصدار كتاب منشور؛ canonical لا يخلط لغات مختلفة.
- لا بيانات اجتماعية أو تقييمات مختلقة.
